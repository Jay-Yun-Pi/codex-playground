# Neon Snake

짙은 배경과 네온 그래픽으로 구성한 반응형 스네이크 게임입니다. 별도의 외부 라이브러리 없이 HTML, CSS, JavaScript만 사용했습니다.

## 주요 기능

- 데스크톱 키보드 방향키 조작
- 모바일·태블릿 터치 스와이프 조작
- 화면 크기와 픽셀 밀도에 맞춰 선명하게 조절되는 게임 보드
- 점수 및 브라우저에 저장되는 최고 점수
- 게임 오버 후 즉시 재시작과 별도의 재시작 버튼
- 접근 가능한 상태 메시지와 키보드 포커스 스타일

## 실행 방법

빌드 과정이나 패키지 설치가 필요하지 않습니다.

### 파일로 바로 열기

프로젝트 폴더의 `index.html` 파일을 브라우저에서 엽니다.

### 로컬 서버 사용하기

프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 [http://localhost:8000](http://localhost:8000)으로 접속합니다.

## 조작 방법

- **키보드:** 방향키(↑, ↓, ←, →)로 이동합니다.
- **터치:** 게임 보드 위에서 이동할 방향으로 스와이프합니다.
- **재시작:** `RESTART GAME` 버튼을 누르거나, 게임 오버 화면에서 방향키/스와이프를 사용합니다.
